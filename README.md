# Estudos Comparativos: Python vs Java
Repositório de estudo comparativos entre Python e Java desenvolvidos durante a graduação.

---

# Objetivos do Projeto
**Análise comparativa:** Entender as particularidades de cada linguagem (produtividade/simplicidade do Python vs. tipagem estática/verbosidade estruturada do Java).
**Portfólio de estudos:** Manter um histórico organizado da evolução no código.

---

## Metodologia de Estudo

Para cada problema abordado:
1. **Implementação em Python:** Foco em legibilidade e rapidez de desenvolvimento.
2. **Implementação em Java:** Foco em estrutura orientada a objetos, tipos de dados explícitos e tratamento de I/O.
3. **Análise de diferenças:** Comparação direta de sintaxe, performance e boas práticas.
